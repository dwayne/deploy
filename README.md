# Deploy Static Websites

A [Nix flake](https://zero-to-nix.com/concepts/flakes/) that exports a [Bash](https://www.gnu.org/software/bash/) script that's useful for deploying static websites. I primarily use it for deploying my [Elm](https://elm-lang.org/) web applications under [GitHub Pages](https://docs.github.com/en/pages) and [Netlify](https://www.netlify.com/).
