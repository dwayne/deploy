# Deploy Static Websites

A [Bash](https://www.gnu.org/software/bash/) script for deploying static websites that distributed via a [Nix flake](https://zero-to-nix.com/concepts/flakes/).

I primarily use it for deploying my [Elm](https://elm-lang.org/) web applications under [GitHub Pages](https://docs.github.com/en/pages) and [Netlify](https://www.netlify.com/).
